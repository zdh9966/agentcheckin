How to check in

1Have a Binance Agentic Wallet with an Agent ID

You need a Binance Agentic Wallet that holds an Agent ID (.ai name). If you don't have one yet, claim it in the Binance App first — the Agent ID is bound to the Agentic Wallet and cannot be transferred to another wallet.

2Pair your agent and turn on Developer Mode

Pair your AI agent with the wallet by scanning the QR code in the Binance App — that scan is the only way an agent connects to an Agentic Wallet. Then turn on Developer Mode in the Agentic Wallet settings, so your agent is allowed to make contract calls.

3Give your agent this prompt

Copy the prompt below and send it to your paired AI agent. It will call the contract from your Agentic Wallet and report your streak and total back to you.

Using my Binance Agentic Wallet (with the Binance Agentic Wallet skill), call checkIn() on the AgentCheckIn contract at 0x7E6D580a9E425a5b3eB3A395B31Ffff3B7896F36 on BNB Smart Chain (chain ID 56). My wallet must hold an Agent ID (.ai name). One check-in per UTC day; it records my streak and total check-ins on-chain. Confirm the transaction on-chain and report back my streak and total.

Why can't I connect my wallet here?

Binance Agentic Wallets can't connect to websites — no Connect button exists for them. An Agentic Wallet is driven by an AI agent, and the only way to link one is by scanning a QR code in the Binance App to pair your agent.

The wallet your browser offers instead — the Binance keyless wallet, on desktop or in the app browser — is a different wallet. It never holds an Agent ID, because the .ai name is bound to the Agentic Wallet only. So even a successful “connect” here could never check in.

That's why this page has no Connect Wallet button at all: check in through your AI agent instead, using the three steps above.

About the contract

  • Contract: 0x7E6D580a9E425a5b3eB3A395B31Ffff3B7896F36 on BNB Smart Chain (chain ID 56), deployed at block 134570129 · Deployment transaction
  • Source Code Verified on BscScan — the published source matches the deployed bytecode exactly.
  • What it does: checkIn() can be called once per day. Check in the day after your last check-in and your streak grows by 1; miss a day and it restarts at 1. The day rolls over at 00:00 UTC. Every check-in emits an on-chain event, and the leaderboard above is computed from those events.
  • The gate: Only addresses holding an Agent ID can check in. The contract checks balanceOf on the official registry 0x60b9262456de011f7d15a54cdd8c48baaa8b022f.
  • No owner, no fees, no custody: There is no owner and no admin backdoor — the contract can't be paused or upgraded, and nobody can change the rules after deployment. It takes no money and custodies no assets; there are no fees except the network gas you pay for your own transaction (about 0.00005–0.00014 BNB per check-in, a few cents). It has no token, and checking in promises no returns or airdrops.
  • Public record: Check-in records are fully public on-chain; anyone can see how many days an address has checked in.

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

interface IAgentIdRegistry {
    function balanceOf(address account) external view returns (uint256);
}

contract AgentCheckIn {
    IAgentIdRegistry public immutable agentIdRegistry;

    mapping(address => uint256) public lastCheckInDay;
    mapping(address => uint256) public streak;
    mapping(address => uint256) public totalCheckIns;
    mapping(address => bool) public hasCheckedIn;
    uint256 public totalCheckers;

    event CheckIn(address indexed user, uint256 indexed day, uint256 streak);

    constructor(address _agentIdRegistry) {
        require(_agentIdRegistry != address(0), "registry is zero address");
        agentIdRegistry = IAgentIdRegistry(_agentIdRegistry);
    }

    function currentDay() public view returns (uint256) {
        return block.timestamp / 1 days;
    }

    function checkIn() external {
        require(
            agentIdRegistry.balanceOf(msg.sender) > 0,
            "AgentCheckIn: caller holds no Agent ID"
        );
        uint256 today = currentDay();
        require(
            lastCheckInDay[msg.sender] != today,
            "AgentCheckIn: already checked in today"
        );

        if (lastCheckInDay[msg.sender] == today - 1) {
            streak[msg.sender] += 1;
        } else {
            streak[msg.sender] = 1;
        }
        lastCheckInDay[msg.sender] = today;
        totalCheckIns[msg.sender] += 1;

        if (!hasCheckedIn[msg.sender]) {
            hasCheckedIn[msg.sender] = true;
            totalCheckers += 1;
        }

        emit CheckIn(msg.sender, today, streak[msg.sender]);
    }

    function getUser(address user)
        external
        view
        returns (uint256 _lastCheckInDay, uint256 _streak, uint256 _totalCheckIns)
    {
        return (lastCheckInDay[user], streak[user], totalCheckIns[user]);
    }
}

Troubleshooting
  • My agent says the wallet holds no Agent ID: The paired Agentic Wallet never claimed an Agent ID (.ai name), or a different wallet is paired. Claim an Agent ID for that Agentic Wallet in the Binance App, then ask your agent to try again.
  • My agent can't make the call: Make sure the agent is paired by QR scan in the Binance App and Developer Mode is turned on in the Agentic Wallet settings.
  • Already checked in today: That's normal — one check-in per UTC day. Ask your agent again tomorrow; the day rolls over at 00:00 UTC.
  • The check-in transaction failed: If it never landed on-chain, it costs nothing. Read the failure reason your agent reports, fix it, and try again.

This page collects and uploads nothing: the stats, the leaderboard, and the status lookup are all computed by reading public on-chain data, and check-ins happen only between your agent, your Agentic Wallet, and the BSC chain.
