About the contract & risks 合约说明与风险

  • What it does: checkIn() can be called once per day. Check in the day after your last check-in and your streak grows by 1; miss a day and it restarts at 1. Every check-in emits an on-chain event, and the leaderboard is computed from those events.它做什么：checkIn() 每天只能调一次；昨天打过卡，连签 +1，断一天就从 1 重新算。每次打卡都发一条链上事件，排行榜就是读这些事件算出来的。
  • The gate: Only addresses holding an Agent ID can check in. The contract checks balanceOf on the official registry 0x60b9262456de011f7d15a54cdd8c48baaa8b022f.门禁：只有持有 Agent ID 的地址能打卡，合约查官方注册表 0x60b9262456de011f7d15a54cdd8c48baaa8b022f 的 balanceOf。
  • What it doesn't do: It takes no money, custodies no assets, has no token, and checking in promises no returns or airdrops. There is no admin backdoor: no owner, it can't be paused, it can't be upgraded — nobody can change the rules after deployment.它不做什么：不收钱、不托管任何资产、没有代币、打卡不承诺任何收益或空投。合约里没有管理员后门，没有 owner、不能暂停、不能升级，部署后谁也改不了规则。
  • Cost: You pay the gas from your own wallet — about 0.00005–0.00014 BNB per check-in (a few cents).费用：每次打卡的 gas 由你自己的钱包付，一次约 0.00005–0.00014 BNB（几分钱）。
  • Public record: Check-in records are fully public on-chain; anyone can see how many days an address has checked in.公开性：打卡记录全在链上公开，任何人都能看到某个地址打了多少天卡。

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

interface IAgentIdRegistry {
    function balanceOf(address account) external view returns (uint256);
}

contract AgentCheckIn {
    IAgentIdRegistry public immutable agentIdRegistry;

    mapping(address => uint256) public lastCheckInDay;
    mapping(address => uint256) public streak;
    mapping(address => uint256) public totalCheckIns;
    mapping(address => bool) public hasCheckedIn;
    uint256 public totalCheckers;

    event CheckIn(address indexed user, uint256 indexed day, uint256 streak);

    constructor(address _agentIdRegistry) {
        require(_agentIdRegistry != address(0), "registry is zero address");
        agentIdRegistry = IAgentIdRegistry(_agentIdRegistry);
    }

    function currentDay() public view returns (uint256) {
        return block.timestamp / 1 days;
    }

    function checkIn() external {
        require(
            agentIdRegistry.balanceOf(msg.sender) > 0,
            "AgentCheckIn: caller holds no Agent ID"
        );
        uint256 today = currentDay();
        require(
            lastCheckInDay[msg.sender] != today,
            "AgentCheckIn: already checked in today"
        );

        if (lastCheckInDay[msg.sender] == today - 1) {
            streak[msg.sender] += 1;
        } else {
            streak[msg.sender] = 1;
        }
        lastCheckInDay[msg.sender] = today;
        totalCheckIns[msg.sender] += 1;

        if (!hasCheckedIn[msg.sender]) {
            hasCheckedIn[msg.sender] = true;
            totalCheckers += 1;
        }

        emit CheckIn(msg.sender, today, streak[msg.sender]);
    }

    function getUser(address user)
        external
        view
        returns (uint256 _lastCheckInDay, uint256 _streak, uint256 _totalCheckIns)
    {
        return (lastCheckInDay[user], streak[user], totalCheckIns[user]);
    }
}

Troubleshooting 出问题了怎么办
  • Tapping Connect does nothing: Most likely the page isn't open in the Binance App's built-in browser. Paste this page's link into the browser inside the Binance App and try again.点连接没反应：多半是没在币安 App 内置浏览器里打开。把本页链接粘到币安 App 的浏览器里再试。
  • It says you have no Agent ID: This wallet never claimed an Agent ID (.ai name). Switch to a wallet that claimed one, or claim one in the Binance App first.打卡提示没有 Agent ID：这个钱包没领过 Agent ID（.ai 名字），换成领过的钱包，或者先在币安 App 里领一个。
  • Already checked in today: That's normal — come back tomorrow. The day rolls over at 00:00 UTC, which is 8:00 AM Beijing time.今天已经打过卡：正常，明天再来。换日时间是 UTC 0 点，也就是北京时间早上 8 点。
  • The check-in transaction failed: If it never landed on-chain, it costs nothing. Read the failure reason, fix it, and tap check-in again.打卡交易失败：没上链就不花钱，看一眼失败原因，处理好后重新点打卡即可。

This page collects and uploads nothing: connecting and checking in go straight from your wallet to the BSC chain, and the checker count and leaderboard are computed by reading public on-chain data.本页不收集、不上传任何信息：连接、打卡都由你的钱包直接和 BSC 链交互，人数和排行榜是直接读链上公开数据算出来的。
